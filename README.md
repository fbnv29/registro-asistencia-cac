# Registro de Asistencia CAC

Prototipo experimental de libros de clases digitales para el Centro Artístico CAC.

**Stack:** Next.js + Netlify (hosting) + Neon PostgreSQL (datos) + GitHub (código).

**Estado:** prototipo en preparación. Solo datos ficticios. Sin despliegue de producción configurado.

> Importante: nunca subir contraseñas, `DATABASE_URL` ni otros secretos al repositorio.
