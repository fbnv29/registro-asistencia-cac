# Identidad CAC

`../favicon.svg` adapta el símbolo del CAC a blanco sobre azul institucional, sin texto para mantener su legibilidad en las pestañas del navegador.

`cac-original.jpg` es una copia sin modificaciones de `normas-graficas-cac/logo-cac/logo cac.jpg`, proporcionado por el usuario.

La interfaz conserva sus proporciones y presenta el logo en blanco mediante CSS (`.monochrome-logo`). El original permanece en color. La paleta procede de `normas-graficas-cac/paleta-y-tipografias/paleta.json`; las fuentes sugeridas son Libre Baskerville y Source Sans 3, servidas localmente.
